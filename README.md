# 42 Projects

Projects from the 42 Network curriculum (1337, Morocco), a peer-learning, project-based programme. Most of the work is low-level systems programming in C and C++: memory management, processes, signals, threads, networking and containers.

Each project lives in its own repository. The most substantial ones come first.

## Highlights

| Project | What it is | Language |
|---|---|---|
| [megashell](https://github.com/Nikat0r/megashell) | A bash-like shell: lexer, grammar-based parser and AST, variable, tilde and wildcard expansion, pipes, redirections, heredocs, logical operators, subshells, and a built-in calculator | C |
| [ft_containers](https://github.com/Nikat0r/ft_containers) | Re-implementation of the C++ vector, map, stack and set in C++98, with their iterators and type traits. The map is built on a red-black tree | C++ |
| [webserv](https://github.com/Nikat0r/webserv) | An NGINX-like HTTP server written from scratch: I/O multiplexing, a configuration file, GET, POST and DELETE request handling, and PHP CGI support | C++ |
| [Inception](https://github.com/Nikat0r/Inception) | Small web infrastructure built from Docker containers and docker-compose | Dockerfile |
| [cub3D](https://github.com/Nikat0r/cub3D) | First-person 3D renderer using raycasting, in the style of Wolfenstein 3D | C |

## Under the Hood

- **Systems programming in C:** manual memory management, file descriptors, processes, pipes and signals.
- **Parsing and language design:** a lexer, a formal grammar and an AST for a shell (megashell).
- **Generic programming in C++:** templates, iterators, SFINAE and red-black trees (ft_containers).
- **Networking:** sockets, I/O multiplexing and HTTP (webserv), plus addressing and subnetting (Net_Practice).
- **Containers and infrastructure:** Docker and docker-compose (Inception).
- **Graphics:** raycasting and real-time rendering (cub3D).
- **Concurrency:** threads, mutexes and synchronisation (Philosophers).
- **Working without a safety net:** peer evaluation and a strict coding standard on every project.
